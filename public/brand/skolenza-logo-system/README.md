# Skolenza Logo System

## Core formula
Royal-blue education cap + blue/navy open-book S + one red right page + navy Skolenza wordmark.

## Colors
- Primary Royal Blue: #2563EB
- Deep Navy: #173B67
- Accent Red: #E52316
- White: #FFFFFF

## Typography
The wordmark uses embedded Poppins ExtraBold in the SVG/PDF exports. Capitalization is `Skolenza`.

## Included variants
- Horizontal full color
- Square full-color app icon
- Horizontal monochrome royal blue
- Horizontal pure white for dark backgrounds

Each variant includes SVG, PDF and transparent PNG exports at 2048, 1024, 512, 256, 128, 64 and 32 pixels. The horizontal PNGs preserve a 4:1 canvas. The square icon PNGs are square. Favicon PNGs at 32x32 and 16x16 plus a combined ICO are included.

Do not recolor individual wordmark letters, add gradients, stretch the logo, or place it on a low-contrast background.
