# Staff structure pages: empty states

## Environment and scope

- Date: 2026-10-18
- Environment: local Angular workspace
- Branch: `development`
- Scope: `features/staff-members/staff-curriculum-delivery/`,
  `features/staff-members/staff-professional-structure/`,
  `features/staff-members/staff-academic-structure/` (templates, components, specs), and
  `shared/components/table-empty-message/table-empty-message.html`

## Problem

Every tab on Curriculum & Lesson Delivery, Professional Structure and Academic Structure showed
its empty state as one line of muted text ("No lesson deliveries yet. Use Record Lesson Delivery
to create one."). It read like a stray row, pointed at a button elsewhere on the page, and gave
no way out when the status filter hid every row ("No inactive job families.").

## Decision

- Reuse the shared `app-table-empty-message` (icon, title, detail line, projected action)
  instead of plain text, so these pages match the table pages.
- No records at all: title "No <things> yet", a detail line saying what the list holds, and the
  tab's own Add button projected into the empty state when the user has Add permission.
- Status filter hid every row (Professional and Academic Structure): title "No <status>
  <things>", detail "Change the status filter to see all <things>.", and an outlined
  "Show all statuses" button that resets the filter.
- Units & Topics with no framework picked: "Pick a curriculum framework", no button (the picker
  sits in the toolbar).
- Staff academic profile sections (teaching assignments, class teacher responsibilities) get the
  icon and detail line but no extra button: the section header already holds it.
- `emptyMessage()` on the curriculum page is removed; the structure pages' `emptyMessage()` now
  returns the title only, with the new `emptyDetail()` returning the detail line.
- Shared component fix on contact: `!text-3xl` became `text-3xl!` (Tailwind v4 rule) and the
  decorative icon got `aria-hidden="true"`.
