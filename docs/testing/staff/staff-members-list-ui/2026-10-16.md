# Staff Members list UI review fixes

## Environment and scope

- Date: 2026-10-16
- Environment: local Angular workspace
- Branch: `development`
- Scope: `features/staff-members` list page (`staff-members.html`, `staff-members.ts`),
  `staff-member-stats`, and `staff-member-role-cell`

## Changes

- Copy: "StaffMember(s)" replaced with "Staff Member(s)" in the stat labels, the page
  title fallback and description, the "Add Staff Member" button, its `expandAriaLabel`,
  the "Import Staff Members" menu item and dialog header, and the empty state. The code
  column header is now "Staff Code".
- Stat icons: On Leave uses `pi-calendar-minus` (was `pi-image`), and Inactive uses
  `pi-user-minus`, so it no longer shares the `pi-users` icon with Total and Active.
- Toolbar: the Professional Structure, Academic Structure and Curriculum & Lessons
  buttons are merged into one outlined "Structure" button. It opens a popup
  `p-tieredmenu` (`structureMenuItems`) with the same three routes. The filter selects
  use `lg:min-w-44` (was `lg:min-w-52`), and the right-hand group is `lg:items-center`.
  Together these stop "Add Staff Member" from being cut off at about 1270px, stop the
  buttons wrapping onto 2 lines, and remove the card's horizontal scrollbar.
- Designation filter: the placeholder reads "Select department first" while the select
  is disabled because no department is chosen.
- Truncated cells: the staff code has a tooltip, and the read-only role chip now shows
  the same `roleView.tooltip` that the manageable chip already had.
- Avatar: the unlabelled red `p-overlaybadge` dot was removed. Its "Click to view
  profile summary" tooltip moved onto the avatar, and `OverlayBadgeModule` was dropped
  from the component imports.
- Status action button: the icon now shows the action, not the state. An active row
  shows an outlined danger `pi-ban` button labelled "Deactivate". An inactive row shows
  an outlined success `pi-check-circle` button labelled "Activate". The icon-only
  button gets `ariaLabel` "<Action> <first> <last>".
- "View missing details": `text-xs` (was `text-[11px]`), `text-zinc-600` and
  `dark:text-zinc-300` (was `text-zinc-500` and `dark:text-zinc-400`).

## Not changed

- The On Leave stat showed 10 with a total of 1. `onLeaveCount` comes from the backend
  statistics endpoint, so this is a data issue to raise with the backend. Angular
  displays the value as received.
- `app-table-search-filter` (the advanced filter button) is `hidden` and disabled in the
  shared component. That is unchanged.
- The row-menu labels (for example "Remove StaffMember") were out of scope. Specs assert
  on them.
