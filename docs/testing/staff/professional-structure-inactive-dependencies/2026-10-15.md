## Expected and actual result

The expected tab order is Job Families, Staff Categories, Capabilities, Duties,
then Positions. New forms must exclude inactive dependencies. An edit form must
retain an already selected inactive dependency in disabled form so historical
data is visible without allowing another inactive selection.

The implementation now applies this rule consistently to category job-family
mappings and Position category, job family, capability, and duty inputs. The
default All status filter exposes inactive records for recovery. Status actions
use the established shared confirmation dialog, where Cancel makes no request
and Proceed invokes the existing mutation.
