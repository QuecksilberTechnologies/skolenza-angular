# Staff Academic Structure UI review fixes (1-4)

## Environment and scope

- Date: 2026-10-16
- Environment: local Angular workspace
- Branch: `development`
- Scope: `features/staff-members/staff-academic-structure` (`.html`, `.ts`, new `.spec.ts`),
  new `shared/utilities/escape-html.ts`

## Changes

1. Dark mode: the panels hard-coded `bg-white` and bare `border`, so in `.dark` the row names,
   form headings and field labels could not be seen. The panels now use
   `border-gray-200 bg-white dark:border-zinc-700 dark:bg-zinc-900`, the same as Professional
   Structure. Row, nav and list-divider borders and the muted text get dark variants as well.
2. Remove buttons: the user confirmed that the backend DELETE endpoints (`deleteMaster`,
   `deleteTeachingAssignment`, `deleteClassTeacherAssignment`) soft-deactivate. The buttons are
   now "Deactivate" (`pi-ban`, outlined danger), matching Professional Structure. They show
   only on active rows and open a `p-confirmDialog` with a danger accept button before the API
   is called. The record name is HTML-escaped because the dialog renders `message` through
   `[innerHTML]`.
3. Default dates: "Effective from" on the teaching and class-teacher forms defaulted to
   `new Date().toISOString().slice(0, 10)`, which is the UTC day. Between 00:00 and 05:30 IST
   that gave yesterday's date. It now uses `localDateKey()` from `shared/utilities/date-key.ts`.
4. Master-form Cancel: the inline object literal (a copy of `emptyMaster()`) is replaced with a
   `resetMaster()` method.

`escapeHtml` moved out of `staff-professional-structure.ts` into
`shared/utilities/escape-html.ts`, and both screens now import it from there.
