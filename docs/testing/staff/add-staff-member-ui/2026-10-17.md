# Add Staff Member form UI review fixes

## Environment and scope

- Date: 2026-10-17
- Environment: local Angular workspace
- Branch: `development`
- Scope: `shared/components/staff-member/staff-member-manage-dialog/*`,
  `shared/interfaces/staff-members/staff-member-basic.ts`,
  `shared/components/navbar/page-info/page-info.html`, `src/styles.css`
- Trigger: user-approved fixes from a screenshot review of `/app/staff/new`

## Decisions

- **Single flowing grid.** All fields after the name row sit in one `md:grid-cols-2` grid,
  so role-gated fields (blood group, mobile, emergency contact, role) drop out without leaving
  half-empty rows. Order: email, DOB, gender, blood group, country, contact fields, role,
  department, onboarding, employment type, staff category, job family, position.
- **Validate on submit.** The primary button is no longer disabled while the form is invalid.
  `onCreate()` calls `markAllAsTouched()` and returns, so every missing field shows its error
  at once instead of only the auto-focused First Name.
- **Red invalid border.** The form opts in with `.form-invalid-visible`; the existing
  `[invalid]` bindings were dead under the app-wide neutralisation in `styles.css`.
- **Date of Birth starts empty.** The control is now `FormControl<Date | undefined>`;
  `[defaultDate]="maxDateOfBirth"` still opens the calendar 18 years back.
- **Dates.** Both pickers use `dateFormat="dd/mm/yy"` and an input icon, matching the
  holiday and billing forms.
- **Dependency hints.** Job Family and Position show "Select a staff category first." /
  "Select a job family first." while their parent is empty.
- **Copy.** Select placeholders use the `Select a <noun>` sentence case of `CountrySelect`.
  Email placeholder is `jane.doe@school.edu`.
- **Action bar.** The host is `block h-full` and the content `flex-1`, so the sticky bar sits
  at the viewport bottom. Its buttons are wrapped in the same `max-w-5xl` container as the card.
- **Page header (global).** Page title gets `leading-tight` so title plus breadcrumb fit the
  55px header. The last breadcrumb renders as plain text (text colour, no pointer).
- **Not changed, by design.** Red Check In button (`checkin.store.ts` colours by state),
  notification badge offset, and the right-edge strip (`[scrollbar-gutter:stable]` in
  `layout.html`). Error text still adds height to its own row; rows align with `items-start`.
- **Code review follow-ups.**
  - Edit mode no longer patches a missing DOB with today; it stays empty so `required` catches it.
  - Invalid submit focuses the first `.ng-invalid[formcontrolname]` field.
  - Dependency hints show only when the parent select is enabled and empty
    (`showJobFamilyHint()` / `showPositionHint()`), so locked self-edit records get no hint.
    Optimus `p-select` has no `aria-describedby` input, so each hint joins the select's
    accessible name through `ariaLabelledBy` (label id + hint id).
  - The last breadcrumb gets `tabindex: '-1'` in `PageInfo`; Optimus already sets
    `aria-current="page"` on it.
  - `h-full` on the host applies in page mode only, not inside the dialog.
- **Known, not changed.** DOB, onboarding and exit dates are still sent with `toISOString()`,
  which moves them to the previous day east of UTC (IST). That predates this change and needs a
  backend contract decision.
- **Locked-fix gate skipped.** The registry at `Skolenza.be/main_branch/LOCKED_FIXES.md`
  returned 404 (raw URL and `gh api`). The user told us to proceed without it.

## Design-system review follow-up (same day)

Second screenshot review against the `skolenza-design-system` skill. All fixes were approved by the
user. The locked-fix registry still returned 404, and the user approved skipping the gate again.

- **Invalid border contrast (global).** `red-400` is 2.77:1 on white and fails the 3:1
  UI-boundary minimum. `.form-invalid-visible` now uses `red-600` (4.83:1) under
  `:root:not(.dark)`. Dark mode keeps `red-400`. This affects all 17 forms that opt in.
- **Primary button fill (global).** White on brand `primary-500` was 3.49:1 for `#4287f5`.
  `SkolenzaPreset` now fills light-theme primary buttons with `{primary.600}` (4.63:1), hover
  with `700` and active with `800`, the same way success and danger already work. A brand hex
  near the 3:1 gate can still land under 4.5:1 at `600`.
- **Stuck spinner.** If `getMasters(JobFamily)` errors, `loadPositions()` never runs, so
  `isLoadingProfessionalStructure` stayed `true`. The error handler now resets it.
- **No spinner on locked selects.** Job Family and Position show `[loading]` only while their
  parent has a value, so they are never disabled and spinning at the same time.
- **Column alignment: reverted.** Moving Middle Name into the two-column grid made the tab and
  screen-reader order First, Last, Middle (WCAG 1.3.2 / 2.4.3). The name row is back to First,
  Middle, Last in `sm:grid-cols-2 lg:grid-cols-3`. The column edges between the name row and the
  grid below do not line up, by design.
- **Positions: latest request wins.** `loadPositions()` unsubscribes the previous request and sets
  the loading flag itself, so a slow response for an earlier category cannot overwrite a newer
  one. `onStaffCategoryChange()` now shows the spinner and clears the previous category's job
  families until the response lands.
- **Card tokens.** The card radius comes from `--p-card-border-radius` (0.8rem) via
  `[style.border-radius]`. The first attempt, `[class.rounded-[0.8rem]]`, rendered square
  corners: Angular cuts a bound class name at its first `.`, so the element got `rounded-[0`
  (confirmed in the browser). Brackets alone bind fine. Light mode uses the shadow only.
  Dark mode adds `border-zinc-800` and `shadow-none`. The sticky bar uses `zinc-200` / `zinc-800`.
  Muted text uses `text-zinc-500`.
- **Not changed.** The page title is still `<h4>` in `page-info.html`. Making it `<h1>` would
  duplicate the `<h1>` that six pages render themselves (staff-category catalogue, form-inputs
  demo, access denied, not found, two learning pages). That needs an app-wide pass. The empty
  space above the full-width sticky bar was left as is.
