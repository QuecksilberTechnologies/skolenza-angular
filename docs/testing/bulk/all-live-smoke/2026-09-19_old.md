## Problems found and fixed

1. The test project referenced the intentionally disabled legacy `AttendancePolicyController`, preventing compilation. The stale contract entry was removed; generic TenantPolicy remains covered by dedicated tests.
2. A one-row applicability collection was serialized as an object. Policy bulk correctly rejected it. The runner now preserves the JSON array and the final run passed.
3. Host tenant selection used a nonexistent `tenantId`; the deployed response supplies the opaque identifier as `id`. After correction, TenantCard passed.
4. Completed jobs do not expose a common `rows` collection. Persisted IDs now come from report CSV; the Employee database ID comes from PolicyAssignment preview where required.
