## Backend status

Checked live Swagger (`/swagger/v1/swagger.json`, 669 paths) on 2026-11-22:

- No payroll, salary or payout endpoint exists.
- Fee endpoints are per student or per admission only (`/api/student/fees/quotes`, `/receipts`,
  `/admissions/{id}/balance`). Nothing aggregates fees by location; summing client-side would
  page every receipt and is not viable.

## Decision

User chose to wire the Angular side now against a proposed contract, accepting that both cards
show their empty state until the backend ships it. The contract extends the existing
`GET /api/Dashboard/INSTITUTION_ADMIN` response (`InstitutionAdministratorDashboardDTO`) with two
`DashboardSection` blocks, so no new HTTP call or service is needed:

```jsonc
"feeCollection": {
  "data": {
    "period": "2026-11",            // yyyy-MM
    "currencyCode": "INR",
    "locations": [
      { "locationId": 1, "locationName": "Main Campus", "totalStudents": 420,
        "expectedAmount": 1260000, "collectedAmount": 1050400,
        "fullyPaidCount": 330, "partiallyPaidCount": 52, "notPaidCount": 38 }
    ]
  },
  "source": null, "isPlaceholder": false, "placeholderFields": null
},
"payrollSummary": {
  "data": {
    "currencyCode": "INR",
    "months": [                      // newest first; first entry drives the headline
      { "month": "2026-11", "totalStaff": 86, "paidCount": 64,
        "paidAmount": 2368000, "pendingAmount": 812000 }
    ]
  },
  "source": null, "isPlaceholder": false, "placeholderFields": null
}
```

- Types: `FeeCollectionSummary`, `LocationFeeSummary`, `DashboardPayrollSummary`,
  `MonthlyPayrollSummary` in `role-dashboard.ts` (`DashboardPayrollSummary` because
  `PayrollSummary` already names the payroll page's stats). Both sections optional on
  `InstitutionAdministratorDashboard`.
- `AdminDashboardStore` exposes `feeCollection`, `feeCollectionPlaceholder`, `payrollSummary`,
  `payrollSummaryPlaceholder`; sections `fee-collection` and `payroll-summary` get per-card
  refresh spinners like the other widgets.
- Cards take `summary` / `placeholder` / `loading` inputs and a `refresh` output, use the shared
  `DashboardCardHeader` (its `Sample data` badge now follows `isPlaceholder` instead of being
  always on), show skeleton rows while loading and an empty state when the section is absent.
- Hard-coded sample constants removed. Currency comes from `currencyCode` (falls back to `INR`).
- Payroll card keeps the strict `canAccess('Payroll')` gate; backend should also send
  `payrollSummary` only to Payroll-permitted callers.
- Fee card still ungated: no fee module key exists. Add one with the backend endpoint.
